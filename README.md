# DropSingleItem

Updated for Valheim 1.0

A fork of [TechGuard/DropSingleItem](https://github.com/TechGuard/ValheimMods/tree/main/DropSingleItem)

[ThunderStore](https://thunderstore.io/c/valheim/p/cjayride/DropSingleItem) | [GitHub](https://github.com/cjayride/DropSingleItem_Fork)

Original Nexus page: [Drop Single Item](https://www.nexusmods.com/valheim/mods/731)

## Right click to place one item instead of the whole stack

- Place 1 item from a picked stack by right-clicking inside your inventory.
- Split half a stack by shift + right-clicking on an item.
- Drop 1 item on the ground by right-clicking outside your inventory.
- Grab a full stack by double left-clicking (merges matching items in the inventory).

## Configuration

A config file **BepInEx/config/TechGuard.DropSingleItem.cfg** is created after running the game once with this mod.

`InventoryUseItem` if you set this to anything other than right-mouse-button, you do not need to hold shift to pick up half a stack.
